#ValidEmX
ValidEmX is a user-friendly Website made with Html, Css and brought to live for validating user's emails by using JavaScript. It is one of my begineer project for learning Web
development. 

## Features 
- Detecting Valid Emails
- checks: tags, role, email address, state of email, validation of mailbox, smtp etc.
- user-friendly website
- Use of Api Key

In this project I learned about the user of API keys in websites, I will be making more projects like this, My sole purpose for learning and pieceing out this project was to learn
the use of Api keys and JavaScript while combining it with Html; through this project I not only learned about Emails and Api keys but their use as well.
